# NGeff

Personal portfolio and project index of Geff, a full stack developer based in Brazil.

This repository serves as a central index for open source projects maintained by NGeff, covering Android applications, APIs, bots, and websites. GLD Solutions is operated jointly with [@lucaaszsx](https://github.com/lucaaszsx).
